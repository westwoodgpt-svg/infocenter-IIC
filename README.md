# Инфоцентр ИИЦ

Дашборд для АНО «Инновационный инжиниринговый центр» (ИИЦ) — React + Vite + TypeScript + Recharts,
собран по образцу [infocenter-RCK](https://github.com/westwoodgpt-svg/infocenter-RCK) (одна и та же
структура из 5 вкладок: Безопасность, Качество, Производство, Затраты, Персонал).

## Данные

В отличие от РЦК-дашборда (который тянет данные из Списков Битрикс24 РЦК), здесь пока используются
статические данные в [`src/data.ts`](src/data.ts) — реальные показатели ИИЦ, перенесённые из документов
папки «Инфоцентр» (сметы, KPI по соглашениям о субсидии, диаграмма вовлечённости):

- **Производство** — контрольные точки по двум соглашениям о субсидии («Содержание» № 40-2025-002065,
  «Финансовая поддержка инжиниринг» № 40-2025-003698): план/факт/% исполнения.
- **Затраты** — сметы ИИЦ по обоим соглашениям (план, факт, остаток).
- **Качество** — динамика уникальных участников семинаров и получателей инжиниринговой поддержки
  по годам (2020–2026), факторы экономической эффективности.
- **Персонал** — ответственные по направлению «Инжиниринг» (Дмитрий Шипилов) и по сметам
  (Владислав Захаров).
- **Безопасность** — структура еженедельного/ежемесячного обзора исполнительской дисциплины
  (пока без данных — заполняется по факту очередного обзора).

Раздельные документы ЦМИТ, Сколково/ФСИ/«Газели» из папки «Инфоцентр» относятся к другим
подразделениям и в этот дашборд не включены.

## Разработка

```bash
npm install
npm run dev       # http://localhost:3000
npm run build      # сборка в dist/
npm run lint        # tsc --noEmit
```

## Деплой

Настроен `vercel.json` (статическая сборка Vite, SPA-рерайт на `index.html`). Живой интеграции
с Битрикс24 Списками (как в РЦК-дашборде) пока нет — при появлении ID Списков ИИЦ её можно добавить
по той же схеме, что используется в `infocenter-RCK/src/App.tsx` (`LISTS`, `loadListRows`).
