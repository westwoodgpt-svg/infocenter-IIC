# Инфоцентр ИИЦ

Репозиторий с шаблонами регулярной отчётности («инфоцентр») для **АНО «Инновационный инжиниринговый центр» (ИИЦ)**.

Собран по образцу Инфоцентра РЦК (`C:\Users\dshp3\Documents\Инфоцентр`) — сохранена структура из 5 разделов и логика/форматы документов (таблицы KPI, сметы, кадровые формы). Программно-специфичное содержимое РЦК (Сколково, ФСИ, «Газели», ЦМИТ, конкретные ФИО и суммы) заменено на общий шаблон под мандат ИИЦ — поддержку промышленного инжиниринга — с плейсхолдерами `[...]` там, где нужны реальные данные ИИЦ.

## Структура

- **Безопасность** — контроль исполнения задач без просрочек.
  - `Безопасность. Анализ за месяц по исполнению задач.docx`
  - `Безопасность. Отсутствие просроченных задач.docx` — требует вставки актуального скриншота из системы постановки задач.
- **Затраты** — сметы по программам ИИЦ (план/факт/отклонение), суммы обнулены.
  - `Затраты. Смета фин.поддержка инжиниринг.xlsx`
  - `Затраты. Смета Содержание.xlsx`
- **Качество** — показатели вовлечённости и экономическая эффективность.
  - `Качество. Инжиниринг.docx`
  - `Качество. Экономическая эффективность.docx`
- **Персонал** — кадровые формы.
  - `Персонал. Дни рождения.docx`
  - `Персонал. Ответственные.docx`
  - `Персонал. Отпуска.xlsx` — унифицированная форма Т-7.
- **Производство** — KPI по субсидируемым направлениям (по аналогии с блоком «Инжиниринг» РЦК).
  - `Производство. KPI содержание.docx`
  - `Производство. KPI фин.поддержка инжиниринг.docx`

## Что нужно заполнить

Все значения в квадратных скобках (`[ФИО]`, `[план]`, `[дд.мм.гггг]` и т.п.) — места для реальных данных ИИЦ: ответственные сотрудники, плановые показатели, суммы смет, реквизиты соглашений о субсидиях. Разделы ЦМИТ, Сколково и «Газели» из РЦК в этот набор не перенесены, так как не входят в мандат ИИЦ; при необходимости их можно добавить по тому же образцу из папки `Инфоцентр`.

Файлы Excel содержат формулы (`SUM`, `IFERROR`) — при открытии в Microsoft Excel они пересчитаются автоматически.
