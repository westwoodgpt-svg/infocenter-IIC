# Инфоцентр ИИЦ

Редактируемый дашборд для АНО «Инновационный инжиниринговый центр» (ИИЦ) — React + Vite +
TypeScript + Recharts, собран по образцу [infocenter-RCK](https://github.com/westwoodgpt-svg/infocenter-RCK)
(та же структура из 5 вкладок: Безопасность, Качество, Производство, Затраты, Персонал).

## Редактор карточек

В отличие от РЦК-дашборда, здесь всё — редактируемые карточки, а не фиксированная вёрстка под
конкретные показатели. Включите **«Режим редактирования»** (кнопка в шапке) — и на любой вкладке
можно:

- **Добавлять / редактировать / удалять** карточки пяти типов: KPI (план/факт/%), График,
  Смета (план/факт), Список, Ответственный.
- **Менять тип графика** прямо в форме: столбчатый, линейный, с областями, круговой — данные
  задаются таблицей «категория × ряды», ряды и категории можно добавлять и убирать.
- **Менять порядок карточек** стрелками вверх/вниз.
- Начать с **пустой вкладки** («Очистить всё» в меню настроек ⚙) и собрать инфоцентр с нуля —
  ровно так, как если бы новому отделу выдали пустой шаблон.

Изменения сохраняются в `localStorage` этого браузера. Чтобы не потерять их или перенести на
другое устройство — **«Экспортировать JSON»** / **«Импортировать JSON»** в том же меню. Там же —
**«Сбросить к примеру ИИЦ»**, который возвращает стартовый набор карточек с реальными данными
ИИЦ (сметы, KPI по соглашениям о субсидии, диаграмма вовлечённости 2020–2026, ответственные) —
он же лежит в [`src/seedData.ts`](src/seedData.ts).

## Разработка

```bash
npm install
npm run dev       # http://localhost:3000
npm run build      # сборка в dist/
npm run lint        # tsc --noEmit
```

## Деплой

`vercel.json` настроен на статическую сборку Vite (SPA-рерайт на `index.html`), продакшн —
https://infocenter-iic.vercel.app, автодеплой при пуше в `master`.

Живой интеграции с Битрикс24 Списками (как в РЦК-дашборде) нет — все данные редактируются вручную
через интерфейс и хранятся в браузере пользователя.
