# Инфоцентр ИИЦ

Редактируемый дашборд для АНО «Инновационный инжиниринговый центр» (ИИЦ) — React + Vite +
TypeScript + Recharts, собран по образцу [infocenter-RCK](https://github.com/westwoodgpt-svg/infocenter-RCK)
(та же структура из 5 вкладок: Безопасность, Качество, Производство, Затраты, Персонал).

## Редактор карточек

Включите **«Режим редактирования»** (кнопка в шапке) — на любой вкладке можно:

- **Добавлять / редактировать / удалять** карточки пяти типов: KPI (план/факт/%), График,
  Смета (план/факт), Список, Ответственный.
- **Менять тип графика**: столбчатый, линейный, с областями, круговой — данные задаются таблицей
  «категория × ряды», ряды и категории можно добавлять и убирать.
- **Менять порядок карточек** стрелками вверх/вниз.
- Начать с **пустой вкладки** («Очистить всё» в меню настроек ⚙) и собрать инфоцентр с нуля.

## Общие данные для всех пользователей (Битрикс24)

Приложение встраивается в Битрикс24 как локальное приложение (iframe). Внутри портала все
изменения сохраняются в общих данных приложения (`app.option` — общий JSON на уровне
приложения, один на весь портал) и видны **любому сотруднику**, открывшему инфоцентр — не только
в браузере того, кто редактировал.

- Бейдж в шапке показывает режим: «Общие данные Битрикс24» (зелёный) или «Автономный режим
  (только этот браузер)» (серый, если открыто вне портала — тогда данные живут в `localStorage`
  этого браузера, как и раньше).
- Кнопка «Обновить» рядом с режимом редактирования подтягивает последние изменения коллег;
  автоматически это происходит и при возврате на вкладку браузера.
- Обновления не в реальном времени: если два человека редактируют одновременно, сохраняется
  последняя версия (last-write-wins), без слияния правок.
- Экспорт/импорт JSON (в том же меню) по-прежнему работают — как резервная копия или чтобы
  перенести данные вручную.

### Как подключить приложение в Битрикс24

Портал: `portal39.mb-product.ru`.

1. **Приложения → Разработчикам → Другое → Локальное приложение.**
2. Путь обработчика: `https://infocenter-iic.vercel.app/`
3. Права: дополнительный scope не требуется — `app.option.get`/`app.option.set` доступны любому
   зарегистрированному локальному приложению без отдельного разрешения.
4. «Использует только API» и BitrixMobile — выключить (как у РЦК-дашборда).
5. Закрепить пункт меню звёздочкой «В избранное» — новые приложения уходят в конец списка «Ещё».

Если `app.option.set` всё же вернёт ошибку доступа — значит на этом портале для локальных
приложений требуется явный scope; тогда нужно добавить его в настройках приложения и переустановить.

### Если POST-загрузка внутри Битрикс24 не заработает на Vercel

Битрикс24 открывает локальные приложения POST-запросом (передаёт токен авторизации), а обычная
статическая раздача на большинстве CDN (включая часть конфигураций Vercel) отвечает на POST
ошибкой 405. Чтобы это обойти, весь трафик здесь идёт через serverless-функцию
[`api/serve.js`](api/serve.js) (см. `vercel.json`), которая отдаёт `dist/` для любого метода —
тот же приём, что и в `infocenter-RCK`. Если по какой-то причине это не сработает на конкретном
плане/конфигурации Vercel, у РЦК-дашборда в `DEPLOYMENT.md` описан рабочий запасной вариант —
хостинг на Cloudflare Workers.

## Разработка

```bash
npm install
npm run dev       # http://localhost:3000
npm run build      # сборка в dist/
npm run lint        # tsc --noEmit
```

Вне Битрикс24 (`npm run dev` в обычном браузере, не в iframe) `window.BX24` не подключается, и
приложение автоматически работает в автономном режиме на `localStorage` — так и тестируется
редактор карточек без необходимости открывать портал.
